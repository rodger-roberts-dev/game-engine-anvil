# Goblin Anvil

**The custom game engine from Goblin Engineering, a Steel & Code workshop**

> Powered by coffee, questionable decisions, and surprisingly good code.

## Purpose

Goblin Anvil is the name for our custom game engine. Its job is to make building small, playable games practical and enjoyable, with room to grow as real projects reveal what the engine needs.

The engine belongs to the existing `game-engine-anvil` codebase. **No second repository is needed.** A future repository rename to `goblin-anvil` is optional—not a prerequisite for development.

## Identity

- **Studio:** Steel & Code
- **Workshop:** Goblin Engineering
- **Game engine:** Goblin Anvil
- **Early game project:** STEELCAST

Goblin Anvil connects our blacksmithing/craftsmanship theme with quirky fantasy humor and old-school game-development nostalgia.

## Engineering direction

1. **Playable first.** Prioritize progress in a real game over abstract engine ambitions.
2. **Keep the engine small.** Add features only for demonstrated use cases.
3. **Reuse existing tools.** If the current toolset can build the next piece of a game, use it.
4. **Discuss missing capabilities before expanding infrastructure.**
5. **Iterate deliberately.** Build, test, learn, and improve through successive games.

These are design principles, not claims that particular engine systems are already implemented.
